03 / Engineering Principles

How we design software differently.

Conventional consumer tech monetizes surveillance and compulsive retention. We build on open formats, bounded sessions, and local-first data ownership.

01 / LOCAL-FIRST

User-Owned Disk Storage

User files and databases reside on local disk in standard SQLite and Markdown formats. Zero proprietary cloud lock-in.

02 / BOUNDED SESSIONS

Finite Software Boundaries

Applications engineered with deliberate completion points. Built to be closed so users can return to real life.

03 / HUMAN-SCALE

Capped Cohorts

1,000-seat community rooms that preserve real human names and nuanced conversation instead of algorithmic outrage mobs.

04 / PRIVATE AI

Client-Side Intelligence

Reasoning models deployed strictly on the user's side of the glass to synthesize knowledge without harvesting personal notes.
